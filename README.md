# Hyperscale-Command

Claude Code mods:

- **brain-map**: Obsidian-style graph of a notes folder. `/brain-map "<path>"` (terminal pane) or `/brain-web "<path>"` (interactive page in Chrome)
- **agent-flow**: live browser view of how agents hand work to each other. `/agent-flow` (or `/agent-pane` for a terminal pane)

Windows only for now (they open Chrome via `cmd /c start`).

## Install (in a local Claude Code terminal session)

```
/plugin marketplace add scroobiusfunk-cell/Hyperscale-Command
/plugin install brain-map@hyperscale-command
/plugin install agent-flow@hyperscale-command
```
