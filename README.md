# Hyperscale-Command

Claude Code mods:

- **brain-map**: Obsidian-style file tree and graph view of a notes folder. `/brain-map "<path>"`
- **agent-flow**: live pane showing how agents hand work to each other. `/agent-flow`

## Install (in a local Claude Code terminal session)

```
/plugin install brain-map --marketplace scroobiusfunk-cell/Hyperscale-Command
/plugin install agent-flow --marketplace scroobiusfunk-cell/Hyperscale-Command
```
